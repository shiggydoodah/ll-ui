# ll-lab Source Context

Lab-only React code. Keep experiments here; promote a pattern to `packages/ui` only when the user decides it belongs in the library.

Current structure:

- `main.tsx` — bootstraps React, imports `styles.css`, creates the TanStack Router from `routeTree.gen.ts`.
- `styles.css` — Tailwind entrypoint: imports the shared `@ll-ui/react` styles plus the `default` and `carbon` themes, and `@source`-scans this app.
- `routes/` — file-based routes. `__root.tsx` is the shell (header, sidebar, theme/mode switching, persisted to `localStorage`); `components/**` hosts one specimen route per library component; `forms.tsx` is the TanStack Form showcase.
- `components/` — `SpecimenPage.tsx` (variant switcher + error-bounded preview), `PropEditor.tsx` (controls generated from `argTypes`), `layout/` (Header, NavSidebar).
- `form/` — reusable form layer: `useAppForm` registry extension, `fields/PasswordField.tsx`, `fields/password-strength.ts`.
- `forms/` — demo forms (Login/Register), zod `schemas.ts`, tests and shared `test-utils.tsx`.
- `nav.config.ts` — sidebar tree; `path` is typed against the generated route tree.
- `types/prop-editor-context.ts` — context wiring between the components layout and the PropEditor.
- `routeTree.gen.ts` — generated by the TanStack Router Vite plugin; never edit by hand.

Rules:

- Import shared components from `@ll-ui/react`; do not copy or modify package code here.
- Style with `--ui-*` tokens via Tailwind shorthand (`bg-(--ui-background)`) — `[var(--…)]` longhand is lint-banned.
- Add tests only when lab behavior becomes complex enough to regress (the form layer is the current example).
